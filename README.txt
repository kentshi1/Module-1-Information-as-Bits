Assignment 1: Converter and Pixel System

Made using Java 17.0.3 with IntelliJ IDEA 2025.2.1

The program does the following:
1. Build an ASCII-to-decimal converter.
2. Build a number-base converter supporting binary, decimal, octal, and hexadecimal.
3. Write a program that reads an image and prints its pixel values.
4. Write a program that consumes pixel values and creates an image.

Additionally, screenshots are in the PDF for
5. Test boundary cases, including zero, the largest supported unsigned value,
and at least one negative two's-complement value.

Parts 1, 2, and 4 use code and files given in class and the Canvas files page.
